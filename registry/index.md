# Registry downloads

The full registry, regenerated on every build from the entries in `mech/`.

- [mechs.yml]({{ '/registry/mechs.yml' | relative_url }}): every Mech as YAML, conforming to the [schema]({{ '/docs/schema/' | relative_url }})
- [mechs.json]({{ '/registry/mechs.json' | relative_url }}): the same as JSON
- [mechs-summary.json]({{ '/registry/mechs-summary.json' | relative_url }}): one slim object per Mech for tables and dashboards
